## 2. Current Data Flow (What the App Actually Uses)

### 2.1 ETHICS Pillar Score Calculation

**Entry point:** `src/lib/truscoreEngine/pillars/ethicsPillar.ts`  
**Called by:** `src/lib/truscoreEngine/index.ts` → `calculateTruScore()`

**Data sources used:**

| Component | Source path | Origin |
|-----------|-------------|--------|
| `resolveBrandToParent()` | `src/data/ethics/brandAliasMap.json` | Copied from Excel extraction |
| `checkBBFAWTier()` | `src/data/bbfaw2024Data.ts` | Generated by extraction script |
| `getBBFAWTierScore()` | Hardcoded in `bbfawService.ts` | Spec formula |
| `getBBFAWImpactScore()` | Hardcoded in `bbfawService.ts` | Spec formula |

**Flow:**

1. Extract brand candidates from `product.brand_owner` and `product.brands`.
2. For each candidate:
   - Resolve via `brandAliasMap.json` (brand → parent, tier, impact).
   - Or fallback to `bbfaw2024Data.ts` (company name → tier, impact).
3. Apply tier score (Tier 1=+6 … 6=−6) and impact score (A/B=+3 … E/F=−3).
4. Base 15 + adjustments, capped 0–25.

**Issue:** The pillar relies entirely on **`src/` data**. None of it is loaded directly from `Database files/ETHICS Pillar`.

### 2.2 BBFAW Service

**File:** `src/services/bbfawService.ts`

```typescript
import { BBFAW_2024_COMPANIES } from '../data/bbfaw2024Data';
// ...
const BBFAW_COMPANIES: BBFAWCompanyData[] = BBFAW_2024_COMPANIES.map(...)
```

- **Source:** `src/data/bbfaw2024Data.ts` (TypeScript)
- **Not used:** `Database files/ETHICS Pillar/bbfaw-2024-data.json`

`bbfaw2024Data.ts` is generated by `scripts/extractBBFAW2024FromDocx.ts`, which:
- Reads from `Database files/ETHICS Pillar/bbfaw-2024-report.docx`
- Writes to:
  - `Database files/ETHICS Pillar/bbfaw-2024-data.json`
  - `src/data/bbfaw2024Data.ts`

If docx parsing fails or yields <50 or >200 companies, the script falls back to a hardcoded `FALLBACK_COMPANIES` list (including incorrect entries such as Kraft Heinz Tier 6). The app then uses this generated/fallback data.

### 2.4 Score Highlights (Ethics)

**Files:**  
- `src/config/scoreHighlightDefinitions.ts` (ETHICS_HIGHLIGHTS)  
- `src/utils/scoreHighlights.ts` (calculateHighlights, selectHighlights)  
- `src/utils/productFlags.ts` (generateProductFlags)  
- `src/features/product/cards/TruScoreCard/TruScoreCard.tsx` (display)

**ETHICS highlights:** BBFAW Tier 1–6 and Impact A–F.

**Trigger logic:** `productMatchesBBFAW(product, tier?, impact?)` in `scoreHighlightDefinitions.ts`:

```typescript
function productMatchesBBFAW(product, tier?, impact?) {
  const candidates = getCompanyCandidatesForBBFAW(product);
  for (const raw of candidates) {
    const resolved = resolveBrandToParent(raw);   // → brandAliasMap (src)
    const company = resolved?.parent_entity_exact ?? raw;
    const data = checkBBFAWTier(company);        // → bbfaw2024Data (src)
    if (!data) continue;
    if (tier != null && data.tier !== tier) continue;
    if (impact != null && data.impactRating !== impact) continue;
    return true;
  }
  return false;
}
```

So:
- Brand resolution uses `resolveBrandToParent` → `src/data/ethics/brandAliasMap.json`
- Tier/impact lookup uses `checkBBFAWTier` → `src/data/bbfaw2024Data.ts`

**Display flow:**

1. `TruScoreCard` calls `generateProductFlags(product)`.
2. `productFlags.ts` calls `calculateHighlights(product)`.
3. `scoreHighlights.ts` iterates `ALL_HIGHLIGHT_DEFINITIONS` and runs each `trigger(product)`.
4. Ethics highlights call `productMatchesBBFAW`, which uses the same `src/` data.
5. `selectHighlights()` picks highlights by pillar and score value.
6. Flags are rendered in the TruScoreCard “Score highlights” section.

**Issue:** Ethics highlights are driven entirely by `src/data/` (brandAliasMap + bbfaw2024Data), not by `Database files/ETHICS Pillar`.

## 3. Summary: Where Data Is Loaded From

| Data | Intended source (source of truth) | Actual runtime source |
|------|----------------------------------|------------------------|
| BBFAW company tier/impact | `Database files/ETHICS Pillar/bbfaw-2024-data.json` | `src/data/bbfaw2024Data.ts` |
| Brand → parent mapping (tier/impact) | `Database files/ETHICS Pillar/...xlsx` (Brand_Alias_Map) | `src/data/ethics/brandAliasMap.json` |
| Parent entities list | `Database files/ETHICS Pillar/...xlsx` (Parent_Entities) | `src/data/ethics/bbfawParents.json` |

---

## 4. Root Causes

1. **Build-time extraction:** Scripts read from `Database files/ETHICS Pillar` but write into `src/data/`. The app only imports from `src/data/`.
2. **No runtime loading from Database folder:** No code loads `bbfaw-2024-data.json` or the Excel at runtime.
3. **Fallback data errors:** `extractBBFAW2024FromDocx.ts` uses `FALLBACK_COMPANIES` on parse failure, and that list contains mistakes (e.g. Kraft Heinz Tier 6 instead of Tier 5).

## 7. Ethics Pillar Score Formula (Reference)

- **Base:** 15  
- **Tier:** 1=+6, 2=+4, 3=+2, 4=+1, 5=−4, 6=−6  
- **Impact:** A/B=+3, C/D=+1, E/F=−3  
- **Cap:** 0–25  

**Example:** Tier 5 + Impact F → 15 − 4 − 3 = 8.
