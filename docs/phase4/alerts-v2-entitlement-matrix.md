# Alerts v2 — free vs premium matrix

| Signal subclass | Free | Premium | Never paywall |
|-----------------|------|---------|---------------|
| Active govt recall (matched) | Yes | Same + optional email digest (future) | **Yes** — must remain visible free |
| Recall “check authority” uncertain state | Yes | — | **Yes** |
| Limited data / source transparency | Yes | Extended source graph | Core line free |
| Methodology link + version | Yes | Deeper article | Link free |
| Preference toggles (base dimensions) | Yes | Advanced dimensions / multi-profile | Core toggles free |
| Boycott / custom list (small) | Yes | Larger lists, sharing templates | N/A |
| Ethics pillar banners (non-safety) | Yes | Historical trend across scans | N/A |
| Premium narrative insights | No | Yes | — |
| Batch export / org dashboard | No | Yes | — |

## Rules

1. **Never paywall** anything required for **legal safety** or **honest non-deception** about the product.
2. Premium may charge for **convenience, depth, and organization**.
3. If a premium feature touches a claim class, it must still link to **free** methodology minimum.
