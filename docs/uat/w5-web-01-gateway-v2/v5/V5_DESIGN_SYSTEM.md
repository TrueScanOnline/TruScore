# V5 Design System — Rveel Product Discovery Experience

## Intent
Image-led product discovery page. Exact shared product is the attraction; four illustrated perspectives create curiosity. Not a card grid clone of the app Result score UI.

## Reproduce from app
- Emerald wallpaper family `#27B899 / #10957E / #087565`
- Mint hero surface `#F7FCFA → #DDF3EC`, rim `#074F42`
- Pillar accent colours Body `#EC514F`, Planet `#008B76`, Claims `#9451E9`, Transparency `#087BF0`
- Fold geometry fold=46 (subtle, one use on hero)
- Type: brand uppercase tracking, bold product name, calm support copy

## Do not reproduce on public web
- Numeric scores, bands, arcs, “Poor/Excellent”
- Fake score bars behind frost

## V5 composition
1. **Product theatre** — large product photograph on a lit stage inside mint frame; soft bloom/spotlight; barcode/brand as caption, not competing hero.
2. **Perspective gallery** — four illustrated scenes (SVG), not pastel tiles. Each is a miniature storyboard with depth layers + soft curiosity veil.
3. **Discovery aperture** — glass lens / portal at gallery centre (no padlock dominance).
4. **Stage** — ivory content slab over emerald atmosphere so desktop is not empty green.

## Perspective illustration briefs
| Key | Visual story |
|---|---|
| Body | Soft lab glass + molecule nodes + apple silhouette (scientific curiosity) |
| Planet | Horizon, leaf canopy, recycle arcs, soft atmosphere |
| Claims | Label strip + magnifier circle + check-mark stamp (inspection, not verdict) |
| Transparency | Layered sheets + link nodes + light shaft (traceability) |

## Interaction
Discover CTA → coordinated veil lift / aperture brighten / CTA spotlight. Curiosity teaser only.
