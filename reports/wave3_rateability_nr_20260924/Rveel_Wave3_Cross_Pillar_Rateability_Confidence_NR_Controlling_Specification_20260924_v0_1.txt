2. Cross-pillar governing doctrine

Every pillar and Overall default internally to NR. The consumer does not see the label “NR”; the score remains unrevealed until its publication gate is met.

Score, Rateability, Confidence, Highlights and S28 are separate layers. None may substitute for another.

Rateability asks whether enough substantive assessment has been completed to reveal a meaningful score.

Confidence applies only after Rateability is cleared and asks how robust the revealed result is given assessment breadth and evidence quality/maturity.

A Rated result receives the Confidence justified by the settled evidence immediately. Limited is the lowest publishable Confidence, not a mandatory first step.

Assessed absence/neutrality may count where the pillar methodology supports it. A fired adjustment is not required to prove assessment.

Score direction does not determine Confidence. A high or low numeric score can carry any permitted Confidence state.

Material unresolved conflict does not create a lower numeric Confidence by itself. A conflicted lane is assessed but unresolved and does not count as a resolved lane for Confidence uplift.

Ordinary OFF/community evidence and primary User Contribution evidence can support publication but do not support High Confidence for MVP. Persistent/corroborated community verification is reserved for post-MVP consideration.

High requires evidence explicitly classified by a governed source mapping as authoritative for the product fact/disclosure being relied upon. Runtime must never infer authority from a source name, URL or brand.

If any required pillar is NR, Overall is NR. Remaining pillars are not renormalised and an internal base 15 is never carried into a public Overall result.

Overall Confidence is the lowest Confidence among the four Rated pillar results.

MVP SIMPLICITY RULEDo not create an evidence percentage, weighted Confidence formula or universal “assessment completeness” score. Use only the deterministic pillar lanes and source-quality rules below.

12. First-paint and refresh contract

On initial scan/retrieval, use the existing consumer loading state “Seeing what we can find…”. All pillar and Overall numeric scores remain unrevealed; no Confidence label or final S26 explanation renders.

The scoring/evidence layer may calculate internally during enrichment, but consumer publication waits for the ordinary initial retrieval/enrichment cycle to settle.

At settlement, publish one consolidated snapshot. Each pillar independently resolves to Rated (numeric score + Confidence + S26) or NR (non-numeric/unrevealed + S26; no Confidence).

After all pillar publication states are settled, Overall resolves: all four Rated -> numeric Overall + Overall Confidence + Overall S26; any NR -> unrevealed Overall + Overall S26; no Overall Confidence.

Routine first-cycle enrichment must not produce Checking -> NR -> Rated milliseconds later, nor flash internal 15/intermediate score/legacy Confidence values.

Use an existing explicit merge/completion boundary where available. Do not invent a timer. If no deterministic completion boundary exists, Cursor must stop that affected first-paint path and report the exact gap before inventing behaviour.

A later genuine reassessment may change NR/Rateability, score or Confidence when genuinely new evidence is admitted (for example a completed contribution, explicit refresh/new scan, or governed later evidence update).

Final animation, “Updating…” treatment, cloak effect and layout remain deferred. Wave 3 only requires accurate state plumbing and minimal UAT-visible rendering.

15. Deterministic decision procedure

Wait for the initial assessment settlement boundary; until then publicationStatus=checking.

Consume each pillar scorer’s existing approved arithmetic and evidence metadata without changing scoring.

Resolve the pillar-specific assessment lanes exactly as sections 4-7 define.

Apply the pillar publication gate. If it fails, set publicationStatus=nr, suppress publishedScore/confidence, resolve the NR S26 code and any actionable contribution opportunity.

If the gate passes, set publicationStatus=rated and publishedScore to the existing approved pillar score.

Assign the structural Confidence from the resolved lanes/fallback route.

Apply only the explicit authoritative-source High uplift where permitted. OFF/community/User Contribution never create High in MVP; do not downgrade below the structural Confidence merely because the source is community/user unless a pillar rule expressly requires it.

Resolve the exact S26 explanation code and contribution opportunity metadata.

After all four pillar states settle, apply the Overall any-NR gate and lowest-Confidence rule.

Publish one consolidated consumer snapshot and append the diagnostic truth to S28.
