3. Required implementation

3.1 Add cross-pillar publication model

Create/reuse a single semantic publication object per pillar and Overall with publicationStatus=checking|nr|rated; internalScore; publishedScore; confidence; assessment-lane state; source-quality/provenance; S26 object; contributionOpportunity; diagnostic reason/code.

Use existing repository naming/types where economical, but produce a one-to-one mapping to the controlling specification in the completion report.

Do not expose internalScore when checking or NR. publishedScore must be null/absent until Rated.

3.2 Body

Nutrition lane resolved by usable governed Nutri-Score A-E OR approved Whole Produce / Nutri-Score-equivalent rescue.

Processing lane resolved by usable governed NOVA 1-4 OR approved inferred NOVA 1 rescue.

Neither lane -> NR. Exactly one -> Rated Limited. Both -> Rated Moderate. Both may resolve High only where both lane evidence is explicitly governed authoritative.

OFF/community/User Contribution evidence must not produce Body High for MVP.

Body additives continue scoring exactly as controlled but must not participate in Body Rateability or Confidence.

3.3 Planet

No usable broad environmental assessment and no +1/+2 governed packaging fallback -> NR.

Packaging fallback +1/+2 -> Rated Limited.

Current usable OFF Green-Score/environmental A-E -> Rated Moderate.

Do not implement an artificial Planet Moderate cap. Any future High path must come only from a separately governed authoritative broad-assessment source/method profile; do not infer one now.

No Planet contribution CTA from this package.

3.4 Claims

Create/consume explicit Packet and Benchmark publication-lane truth independent of the fired-adjustment ledger.

Packet lane assessed when governed packet claims/certifications assessment is substantively complete: scored finding, governed zero-adjustment finding, or admissible established absence all count.

Benchmark lane assessed only when BOTH KTC and BBFAW reach successful terminal governed check outcomes. Hit/no-hit both count; failed/pending/unresolved/incomplete do not.

Neither lane -> NR. One lane -> Rated Limited. Both lanes -> Rated Moderate. High requires both lanes and authoritative packet evidence; ordinary OFF/User Contribution remains no higher than Moderate.

Do not manufacture +0 fired adjustments. A no-adjustment lane may still support publication and Confidence.

Preserve existing Claims v0.2 scoring assessment state for diagnostics, but do not force publication logic to infer lane completion from that three-state field alone if it cannot represent a governed zero-adjustment assessment accurately.

Emit Claims packet contributionOpportunity when the Packet lane is incomplete, with routeStatus=future unless a separately governed Wave 4 route is present. Do not render a dead CTA/card.

3.5 Transparency

Ingredient lane resolved when usable governed ingredient wording has been assessed under Open v15, including zero governed flags.

Origins lane resolved only for governed resolved disclosure outcomes. Insufficient evidence is unassessed/unresolved. Conflicting origin evidence is assessed_unresolved_conflict and does NOT count as resolved.

No resolved lane -> NR. One resolved lane -> Rated Limited. Both resolved -> Rated Moderate. Both explicitly authoritative for the scored disclosure -> High.

Ingredient resolved + Origins conflict -> Rated Limited with the governed conflict S26 explanation.

OFF/community/User Contribution evidence must not produce Transparency High for MVP.

3.6 Overall

If any pillar is NR, Overall is NR/unrevealed. Do not renormalise and do not insert base 15 for an unrated pillar.

If all four are Rated, publish existing Overall arithmetic and set Overall Confidence to the lowest pillar Confidence: any Limited -> Limited; otherwise any Moderate -> Moderate; all High -> High.

Overall must receive its own S26 object. Do not make the UI reconstruct Overall explanation from pillar S26 strings.

6. First-paint / refresh implementation

While the ordinary initial scan/enrichment cycle is active, render the existing “Seeing what we can find…” state. Keep all pillar and Overall numeric scores suppressed; no final Confidence or S26.

Use the existing deterministic enrichment merge/completion signal as the publish barrier. Do not introduce a timer.

Rated pillar -> numeric score + Confidence + S26. NR pillar -> non-numeric/unrevealed + S26, no Confidence.

7. Source-quality mapping

Implement/consume only three semantic source-quality classes: authoritative; community_or_user; other_or_unknown.

Map OFF/community data and primary User Contributions to community_or_user.

Do not classify any source authoritative from its URL/name/string. authoritative requires an existing or separately supplied governed mapping that states the source is authoritative for that product fact/disclosure.

Treat current OFF Green-Score as the current Moderate Planet route; do not create an artificial cap flag.

Claims KTC/BBFAW are governed benchmark assets for Benchmark-lane assessment. Packet evidence still controls whether Claims can reach High.

If current repository source values do not map deterministically under these rules, use other_or_unknown, report them, and do not invent a higher classification.
