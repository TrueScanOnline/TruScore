# Barcode Test Script Usage Guide

## Overview

The TrueScan Barcode Performance Test Script allows you to test individual or multiple barcodes and generate comprehensive logs showing:

- ⏱️ **Performance Metrics**: How long it takes to find the product and calculate the TruScore
- 📊 **Overall Performance**: Total time for complete product lookup and scoring
- 🗄️ **Database Tracking**: Which database(s) were queried and used for data
- 🏆 **TruScore Breakdown**: Detailed calculation of each of the 4 pillars (Body, Planet, Care, Open)
- 📋 **Data Sources**: Exact sources for ingredients, nutrition, allergens & additives, country of origin, and score highlights
- 🔍 **Pillar Calculations**: Step-by-step breakdown of how each pillar calculates its score

## Prerequisites

1. **Node.js**: Ensure Node.js is installed (v16 or higher recommended)
   ```powershell
   node --version
   ```

2. **TypeScript Runner**: The script uses either `tsx` or `ts-node` to run TypeScript
   - If neither is installed, the PowerShell script will attempt to install `tsx` globally

3. **Project Dependencies**: Ensure all npm dependencies are installed
   ```powershell
   npm install
   ```

## Usage

### PowerShell Command

#### Single Barcode
```powershell
.\scripts\testBarcodePerformance.ps1 -Barcodes "9300633910198"
```

#### Multiple Barcodes
```powershell
.\scripts\testBarcodePerformance.ps1 -Barcodes "9300633910198","0726684754229","1234567890123"
```

#### With File Output
```powershell
.\scripts\testBarcodePerformance.ps1 -Barcodes "9300633910198","0726684754229" -OutputToFile -OutputPath "test_results.json"
```

### Direct TypeScript Execution

You can also run the TypeScript script directly:

```powershell
# Using tsx (recommended)
tsx scripts/testBarcodePerformance.ts 9300633910198 0726684754229

# Using ts-node
ts-node scripts/testBarcodePerformance.ts 9300633910198 0726684754229
```

## Understanding the Pillars

### Body Pillar (0-25 points)
Measures nutritional quality and safety:
- **Base**: 15 points
- **Nutri-Score**: A=+10, B=+5, C=0, D=-5, E=-10
- **Additives**: Penalties based on IARC classification and safety ratings
- **NOVA Processing**: Unprocessed=+3, Ultra-processed=-8
- **Minimum Floor**: 2 points (all products get at least 2)

### Planet Pillar (0-25 points)
Measures environmental impact:
- **Base**: 15 points
- **Eco-Score**: A=+10, B=+5, C=0, D=-5, E=-10
- **Palm Oil**: Non-certified=-8, Certified=0
- **Packaging**: Recyclable bonus (+2 to +5)
- **Farming Impact**: High-impact=-5, Low-impact=+3

### Ethics Pillar (0-25 points)
Measures ethical standards:
- **Base**: 15 points
- **Certifications**: Fairtrade=+8, Organic=+7, etc. (cap +15)
- **Animal Cruelty**: Major=-15, Minor=-5
- **Labor Violations**: Major=-15, Minor=-5
- **Recalls**: Recent recalls=-10

### Open Pillar (0-25 points)
Measures transparency:
- **Base**: 15 points
- **Ingredients Disclosure**: Full=0, Partial=-5, None=-5
- **Hidden Terms**: 1=-5, 2=-10, 3+=-15
- **Origin Information**: Missing=-8
- **Transparency Bonus**: +2 to +5 for zero hidden ingredients

## Troubleshooting

### Error: Node.js not found
- Install Node.js from https://nodejs.org/
- Ensure Node.js is in your PATH

### Error: TypeScript runner not found
- The PowerShell script will attempt to install `tsx` automatically
- Or install manually: `npm install -g tsx`

### Error: Module not found
- Run `npm install` in the project root
- Ensure you're in the correct directory

### Product not found
- Check that the barcode is valid (8-14 digits)
- Some products may not exist in any database
- Try a well-known product barcode first

## Advanced Usage

### Custom Performance Metrics

The script tracks:
- **Fetch Time**: Time to retrieve product data from databases
- **TruScore Time**: Time to calculate the TruScore (typically < 50ms)
- **Total Time**: Combined time for complete lookup

### Database Tracking

The script identifies which databases contributed data:
- **Primary Source**: Main database that provided the product
- **All Sources**: All databases that contributed any data
- **Databases Queried**: All databases that were checked (even if no data found)

Common databases include:
- `openfoodfacts` - Open Food Facts (primary for food)
- `openbeautyfacts` - Open Beauty Facts (cosmetics)
- `usda` - USDA FoodData (US products)
- `healthcanada` - Health Canada (Canadian products)
- `nzfcd` / `afcd` - FSANZ databases (AU/NZ products)
- `web_search` - Web scraping fallback

## Output Files

When using `-OutputToFile`, two files are created:
1. **JSON file**: Structured data for programmatic access
2. **_full.txt file**: Complete console output for review

## Notes

- The script uses the regular `fetchProduct` function (not optimized version) for better database tracking
- Performance may vary based on network conditions and database availability
- Some databases may have rate limits
- Results are cached to improve subsequent lookups
