Score Highlights - Complete Reference Document (v7 Overhaul)Purpose: This document catalogs all possible Score Highlights for the TruScore card, fully aligned to the 4-pillar methodology (Body, Planet, Ethics, Open). It defines generation rules, UI display logic, and overrides to ensure highlights are evidence-based, non-alienating, and focused on scored elements only (no vegan/allergen/boycott scoring—handled via separate banner alerts modal). Use this to implement generateProductFlags() in src/utils/productFlags.ts and UI in src/features/product/cards/TruScoreCard/TruScoreCard.tsx.Last Updated: 2025 (Post-Overhaul v7)Key Changes in v7:Removed "Data Sources Reference" per user directive (full DBs in pillar scoring specs).Tie-breaker logic per pillar for equal abs(value) measures, prioritizing virality/rage drivers (e.g., carcinogens > ultra-processed in Body).Override: All measures with abs(value) >=7 must be included, even breaching max 8 (soft cap at 12 to prevent UI bloat).Alcohol override applies to Nutrient Profile A/B/C explainers.Verbatim pull from x-pillar table for all Highlights Commentary (titles), Explainer (descriptions), and External Resource (pop-up links).Re-branded "Care" to "Ethics" pillar per executive decision.All pillars capped at max 25 points.Pillar floors: 0 for Planet/Ethics/Open; 2 for Body (avoids total wipeout on health sentiment).Triggers rely solely on OFF data (e.g., nutriscore_grade, no geo-fallbacks for MVP).OverviewScore Highlights provide quick visual indicators in the TruScore card: Green flags for positive attributes (high scores), Red flags for concerns (low/negative scores). Derived exclusively from the x-pillar scoring table, with max 8 highlights (top 2 pos + top 2 neg per pillar, skipping defaults)—overridable for high-impact measures. Generated via generateProductFlags() using product data; minimal overrides in src/config/scoreHighlightOverrides.ts for data consistency only.Highlights promote user trust by being transparent, actionable, and tied to public sources. No moralizing—focus on facts for consumer empowerment across G20 markets.Highlight CategoriesScore Highlights are organized into 4 pillars (from x-pillar table):Body - Health/nutrition impacts (max 25, min 2)Planet - Sustainability/environmental impacts (max 25, min 0)Ethics - Ethics, welfare, and community concerns (max 25, min 0)Open - Transparency and disclosure (max 25, min 0)Complete List of All Possible Score HighlightsHighlights are dynamically generated from the x-pillar table's "Scoring Measure" and "Score Value". Each maps to:Title/Commentary: Verbatim from "Highlights Commentary" column.Type: Green (positive score value) or Red (negative/zero score value).Category: Matches pillar.Severity: High (abs(value) >=5), Medium (abs=3-4), Low (abs=1-2) — for UI bolding/sorting.Description/Explainer: Verbatim from "Explainer" column (shown in pop-up).Trigger Condition: Based on product data matching "Scoring Measure" (e.g., nutriscore_grade == 'a').Data Source: From table's "Data Element".External Resource: Verbatim from "External Resource" column (linked in pop-up as "Want to know more? Click <here>.").UI Click-Through: Each highlight is clickable; triggers a closable pop-up with Explainer text + "Want to know more? Click <here>." linking to External Resource. Pop-up: Simple modal (e.g., React Native Modal), close via 'X' or backdrop tap.1.
