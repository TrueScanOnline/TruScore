# Deploy to Vercel

## Quick Deploy

Run these commands:

```powershell
# Make sure you're logged in
vercel login

# Deploy to production
vercel --prod
```

## After Deployment

1. Copy the deployment URL shown (e.g., `https://truescan-backend-abc123.vercel.app`)
2. Return to project root
3. Update `.env` file with the URL

## Check Deployment

```powershell
vercel ls
```

This shows all your deployments.
