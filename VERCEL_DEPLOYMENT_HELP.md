# Vercel Deployment - Answer These Questions

When Vercel asks these questions, here's what to answer:

---

## Questions and Answers:

### 1. "Set up and deploy?"
**Answer:** `yes`

### 2. "Which scope should contain your project?"
**Answer:** Choose your scope (e.g., "Leighton's projects")

### 3. "Link to existing project?"
**Answer:** `no` (create new project)

### 4. "What's your project's name?"
**Answer:** `TruScore` (or any name you prefer)

### 5. "In which directory is your code located?" ⚠️ **IMPORTANT**
**Answer:** `./` (just type: dot slash)

**DO NOT enter:**
- ❌ `C:\TrueScan-FoodScanner`
- ❌ `./C:\TrueScan-FoodScanner`
- ❌ Any absolute path

**DO enter:**
- ✅ `./` (current directory - you're already in the right place!)

---

## Complete Answer Sequence:

```
? Set up and deploy? yes
? Which scope? [Choose your scope]
? Link to existing project? no
? What's your project's name? TruScore
? In which directory is your code located? ./
```
