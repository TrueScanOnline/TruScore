TESTFLIGHT SETUP FOR AUSTRALIAN TESTER
═══════════════════════════════════════════════════════════════

After build is processed in App Store Connect:

1. Go to: https://appstoreconnect.apple.com
2. Navigate to: My Apps → TrueScan → TestFlight
3. Wait for build to appear (may take 10-30 minutes)
4. Add build to TestFlight testing
5. Add tester email (Australian user with iPhone 11)
6. Send TestFlight invitation email
7. Tester installs TestFlight app and accepts invitation
8. Tester can download and test the app

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

If expo-doctor still shows warnings:
- The "native project folders" warning is expected if you have ios/ folder
- This is a non-critical warning for EAS Build
- Build will still work correctly

If build fails:
- Check EAS dashboard: https://expo.dev/accounts/[your-account]/projects/truescan-food-scanner/builds
- Review build logs for specific errors
- Verify certificates and provisioning profiles are valid

If submission fails:
- Check App Store Connect for error messages
- Verify Apple Developer account has proper permissions
- Ensure app is in correct state for submission
